Pneumonia Detection Using Chest X-rays

Overview

This project uses deep learning to classify chest X-ray images into two categories: Normal and Pneumonia. The dataset was obtained from Kaggle.

Technologies Used

- Python
- PyTorch
- Deep Learning
- Chest X-ray Image Processing
- Kaggle

Methodology

- Prepared and preprocessed chest X-ray images.
- Trained a deep learning model for 8 epochs.
- Evaluated the trained model on 619 unseen test images.

Results

- Test Accuracy: 89%
- Pneumonia Recall: 99%
- Missed pneumonia cases: 2 out of 390 pneumonia test images.

Project Purpose

This project demonstrates practical skills in deep learning, image classification, model training, and evaluation.
